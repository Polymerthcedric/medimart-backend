# Medimart Backend

The engine behind Medimart. A Flask REST API that handles transactions, M-Pesa integrations, and AI logic.

## The Stance
Backends should be boring, reliable, and fast. No microservices architecture to manage a single store. It's a majestic monolith built in Python. It processes data and gets out of the way.

## Running
1. `pip install -r requirements.txt`
2. `python app.py`
